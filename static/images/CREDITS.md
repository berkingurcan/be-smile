# Be Smile illustration assets

- `good-energy-poster.svg`: original vintage-inspired cut-paper composition for the hero. Abstract figures, a golden sun and flowing forms express movement and shared energy.
- `together-in-motion.svg`: original companion composition for the crew-life section.

Both are editable, resolution-independent SVGs in the Sunshine palette. The artwork extends the existing Be Smile illustration language. Text remains in HTML for translation and accessibility. No photography, external fonts or third-party image requests are used by these assets.
